# 🏢 Employee Management System

### A Smarter Way to Manage Employees and Workplace Operations

Employee Management System is a web-based application designed to simplify workforce management. It provides a centralized platform where administrators can manage employee information, maintain records, and monitor workforce activities while employees can access their personal profiles and relevant information.

## ✨ Features

* 🔐 **Authentication** – Separate login access for administrators and employees.
* 👥 **Employee Management** – Manage employee profiles and information.
* 📊 **Dashboard** – Get an organized overview of employee-related information.
* 📝 **Employee Records** – Maintain and manage employee details.
* 👤 **Profile Management** – Access and manage employee profile information.
* 📱 **Responsive Design** – Access the application across desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

* **Frontend:** React.js, Bootstrap, React Router DOM
* **Backend:** Python 3.12
* **Database:** ot xidentifiable from the available source code
* **Authentication:** Axios, REST API integration

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/prasanakannan/employee-manegemenr-system.git
```

### 2. Navigate to the project directory

```bash
cd employee-manegemenr-system
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

*Note: These commands assume a single npm-based application. If your project has separate frontend and backend folders, configure and run them independently.*
